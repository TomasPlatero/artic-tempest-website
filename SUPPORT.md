# Support

Need help with Artic Tempest?

## Best places to ask

- **Bugs or feature requests:** open a GitHub issue.
- **Security concerns:** use `SECURITY.md` and report privately.
- **Project navigation:** start with [docs/index.md](docs/index.md).
- **How a section works:** read the matching area note in `docs/` first.

## What to include

When you ask for support, include:

- What you were trying to do.
- What happened instead.
- Any error messages or screenshots.
- The branch/commit and environment if relevant.

## Direct contact

If a private conversation is needed, use the contact channel listed in `SECURITY.md`.
