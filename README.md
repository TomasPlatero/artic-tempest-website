## What this repo contains

- Public content: home, news, recruitment, progression, culture, streams, help, legal pages.
- Authenticated/member areas: personal characters, notifications, raid area, recruitment flows.
- Admin/configuration areas: guild settings, roles, accounts, news, recruitment, applications, integrations.
